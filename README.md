# Rome Dream Home — Welcome Books

Static site (HTML/CSS/JS, no framework, no build server needed). Deployable as-is to GitHub Pages.

```
site/
├── index.html                 ← branded landing (generated)
├── manifest.webmanifest
├── assets/                    ← SHARED by every apartment
│   ├── css/style.css          ← the whole theme (bordeaux · ivory · travertine · gold)
│   ├── js/app.js              ← the engine: renders any apartment from its data
│   ├── js/i18n.js             ← shared UI strings in IT / EN / FR / ES / DE / AR
│   ├── js/icons.js            ← icon set (Lucide, ISC licence + custom Roman icons)
│   ├── img/                   ← logo (white/bordeaux, transparent), skyline, favicons, OG image
│   └── audio/                 ← optional background music (Kevin MacLeod, CC BY 4.0)
├── babuino/                   ← ONE FOLDER PER APARTMENT  →  …/romedreamhome/babuino/
│   ├── data.json              ← all apartment content + translations (source of truth)
│   ├── img/*.webp             ← apartment photos (name-sm.webp 640px + name.webp 1400px)
│   └── index.html             ← generated by _tools/build.py (do not edit by hand)
├── _template/                 ← page templates (ignored by GitHub Pages/Jekyll)
└── _tools/build.py            ← generator (Python 3, standard library only)
```

## Add a new apartment
1. Copy `babuino/` to a new folder, e.g. `trevi/` (folder name = URL = `slug` in data.json).
2. Edit `trevi/data.json`: name, address, host, `wifi`, `lockboxCode`, check-in/out times, photos, sections.
   Every guest-facing text is an object `{ "en": …, "it": …, "fr": …, "es": …, "de": …, "ar": … }`.
3. Put photos in `trevi/img/` as `name-sm.webp` (640 px wide) and `name.webp` (1400 px wide).
4. Run `python3 _tools/build.py` → writes `trevi/index.html` and refreshes the landing page.
   `python3 _tools/build.py --check` reports missing translations or photo files.

Section blocks available in data.json: `lead, text, heading, photo, signature, closing, time, steps,
arrival, code, notice, tax, address, tabs (airport routes), wifi (with QR), list, rules, amenities,
features, places, dial, hostActions, checklist, host, review`.

Optional: set `"baseUrl"` in `_tools/config.json` (e.g. `https://<user>.github.io/romedreamhome/`) for
absolute link-preview images; set `"listOnLanding": false` to hide the apartment list on the landing page
(guests then only reach a guide via its direct link — recommended, since guides contain door/Wi-Fi codes).

Local preview: `cd site && python3 -m http.server 8000` → http://localhost:8000/babuino/
